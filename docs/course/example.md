# 示例课程文档

这篇文章告诉你课程笔记该怎么写。把下面的内容当作"模板"，照着格式替换成你自己的内容即可。

## 怎么写一篇文章

写文章用的是 Markdown 格式，很简单：

- 一行 `#` 开头的是**大标题**，`##` 是**二级标题**，`###` 是**三级标题**
- 普通文字直接写就行
- 段落之间用**空一行**隔开

## 常用格式示例

**加粗文字**：两个星号包住文字。

*斜体文字*：一个星号包住文字。

> 引用别人的话：行首加一个大于号。

列表：

1. 第一条
2. 第二条

代码块，用三个反引号包住：

```python
print("Hello, L&T!")
```

图片，中括号里写说明，括号里写图片路径：

![示例图片](图片地址.jpg)

## 小技巧

- 写完保存后，浏览器页面会自动刷新，不用重新启动服务
- 每个 `docs` 下的 `.md` 文件就是一个网页
- 如果想让某个 `.md` 文件出现在顶部菜单里，去 `mkdocs.yml` 的 `nav` 里加一行即可
